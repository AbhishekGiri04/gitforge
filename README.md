## 🚀 Getting Started

### Prerequisites
- Git 2.30+ installed
- GitHub account
- Code Editor (VS Code recommended)
- Terminal/Command Line access

### Quick Start

```bash
# Clone repository
git clone https://github.com/AbhishekGiri04/GitForge.git
cd GitForge

# Read Git commands reference
cat git-commands.md

# Study Git theory
cat git-theory.md
```
